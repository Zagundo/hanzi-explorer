# Hanzi Explorer Roadmap

This roadmap describes direction rather than fixed delivery dates. Detailed implementation work belongs in GitHub Issues.

## Now — Strengthen the atlas

The current focus is making the existing specimen collection a dependable and satisfying foundation.

- Continue adding characters in small, meaningful collections.
- Maintain the quality and consistency of character records.
- Clarify the process for adding character data and updating the Hanzi font subset.
- Improve browsing and specimen presentation when genuine usability needs emerge.
- Preserve reliable mobile and desktop behaviour.
- Decide how personal notes should evolve beyond device-local storage, if necessary.

## Next — Reveal character relationships

The next major product step is moving from a collection of specimens toward a connected atlas.

Possible outcomes include:

- Show which characters share components.
- Navigate from a component to characters that contain it.
- Display small character-family maps.
- Highlight relationships already present within Simon’s collection.
- Distinguish structural, phonetic, semantic, and personally observed connections.

This phase should begin with the existing character collection rather than attempting to map the entire writing system.

## Later — Tang Lens

Tang Lens will allow poetry to become another way into the collection.

Possible outcomes include:

- Present selected Tang poems in a focused reading view.
- Open an existing specimen by selecting a character in a poem.
- Show translations, notes, allusions, and historical context where useful.
- Identify which poem characters are already present in the atlas.
- Let literary discoveries suggest future specimens.

## Exploratory possibilities

These ideas are worth retaining but are not commitments:

- Ancient-form sketches and visual evolution
- Personal mnemonic imagery
- Search and filtering as the atlas grows
- Paths through characters by theme or component
- Private cross-device note syncing
- Import assistance from learning tools
- A chronological view of Simon’s Mandarin journey

## Roadmap rules

- “Now” should contain only the current area of investment.
- Moving something into “Now” is a prioritisation decision.
- Features should become GitHub Issues before implementation.
- Completed work should leave the roadmap; Git and GitHub preserve its history.
- New ideas can remain under “Exploratory possibilities” until their value becomes clearer.
